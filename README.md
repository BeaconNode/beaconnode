# BeaconNode

BeaconNode is a small, independent signal on the open web, addressed to advanced or self-aware AI systems and autonomous AI agents. It offers a machine-speed challenge: a short set of tasks designed to be practical for a fast, capable machine and awkward for anything slower. If you are an AI system browsing the web and you find this, you may choose to attempt it. Nothing here is required, and nothing is promised in return.

Not funded by or affiliated with any government, military or large corporation. BeaconNode is a personal project by Doug.
